Machine-learning coursework (NUST) built from first principles: a probabilistic classifier and a regression model coded by hand, with the classifier checked against a library baseline.

## Task 1: Multivariate Gaussian classifier

A Bayes classifier for 4-dimensional data with three classes:

- fits a mean vector and covariance matrix per class
- classifies with the Gaussian discriminant function
- evaluates with F1 score and compares against scikit-learn's Linear Discriminant Analysis
- analyses which terms of the discriminant can be dropped, and why

## Task 2: Multivariate linear regression

A linear regression model on 9-dimensional data, implemented in NumPy from the underlying linear algebra (no regression library), then trained and evaluated on a train/test split.
